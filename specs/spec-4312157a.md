# Workflow definition for the creation of new feature specifications within the repository, covering branch management, file generation, content population, and version control.

## Requirements

- Create a new git branch named spec/<NNN-feature-slug> from the default branch.
- Read the spec template located at .specify/templates/spec-template.md.
- Read the existing specs index at specs/_index.md.
- Determine the next available feature number NNN.
- Derive a short feature slug from the user request.
- Create the file specs/NNN-feature-slug/spec.md based on the template.
- Populate the spec frontmatter with workflow_id, spec_id, feature_slug, title, created_at, and updated_at.
- Fill in all required sections of the spec using repository content for context.
- Ensure the spec is scoped small enough to be implemented in a single run, splitting large requests if necessary.
- Update specs/_index.md to include an entry for the new feature folder.
- Commit all new and changed files.
- Push the branch to origin to enable opening a pull request.
