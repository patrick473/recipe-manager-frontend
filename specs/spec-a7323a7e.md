# Add a mango-themed option alongside the existing cucumber theme and enable theme switching from the settings page.

## Requirements

- Create a new theme called 'mango' alongside the existing 'cucumber' theme.
- Implement the 'mango' theme to visually distinguish it from the 'cucumber' theme, following the mango theme concept.
- Add functionality on the settings page to allow users to switch between themes, specifically between 'cucumber' and 'mango'.
- Ensure the theme switch updates the application appearance immediately upon user selection.
- Persist the selected theme preference so that it is retained across user sessions.
